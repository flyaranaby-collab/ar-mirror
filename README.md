# 실시간 착용 거울 (AR Mirror)

카메라로 얼굴·목·손을 실시간 인식해서, 액세서리 디자인 보드에서 만든 귀걸이·목걸이·팔찌·반지를 실제 크기 비율로 착용해 보여주는 웹페이지입니다.

- 주소: https://flyaranaby-collab.github.io/ar-mirror/
- 인식 기술: Google MediaPipe Tasks Vision (얼굴 Face Landmarker, 손 Hand Landmarker, 자세 Pose Landmarker) — 브라우저 안에서 동작, 영상은 기기 밖으로 나가지 않음
- AI 스타일 분석: 피부 톤·언더톤·얼굴형을 기기 안에서 측정해 어울리는 조합 추천
- 디자인 불러오기: 디자인 보드 → 저장·백업 → 전체 백업 복사 → 이 페이지에 붙여넣기
